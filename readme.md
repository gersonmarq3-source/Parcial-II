## Descripción del Proyecto
Este proyecto consiste en una solución de análisis de datos e inventario para una empresa salvadoreña con presencia en cinco sucursales principales:
* **San Salvador**
* **Santa Ana**
* **San Miguel**
* **La Libertad**
* **Sonsonate**

El sistema integra:
1. Un conjunto de datos de inventario en formato CSV generado y procesado con **Pandas**.
2. Una interfaz gráfica interactiva desarrollada con **PyQt5** y gráficos integrados de **Matplotlib**.
3. Un informe de consultoría gerencial en formato PDF con análisis, conclusiones y recomendaciones estratégicas.

---

## Estructura del Repositorio
* `codigo_fuente.py`: Aplicación en PyQt5 con visualizaciones en Matplotlib.
* `inventario_sucursales.csv`: Conjunto de datos con la estructura del inventario.
* `informe_consultoria.pdf`: Informe de consultoría para la gerencia.
* `requirements.txt`: Dependencias y librerías necesarias del proyecto.
* `.gitignore`: Archivos y carpetas excluidos del control de versiones.
* `README.md`: Documentación del proyecto.
